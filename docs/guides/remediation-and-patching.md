# Automated Remediation and Semantic Patching Guide

This guide explains how to use PQCanary's `SemanticPatcher` to automatically modernize vulnerable cryptographic code, generate unified diffs, and create automated Git pull requests.

---

## 1. How Semantic Patching Works

Identifying cryptographic vulnerabilities is only the first half of the migration lifecycle. PQCanary's `SemanticPatcher` analyzes the concrete syntax tree and replaces insecure or classical algorithms with post-quantum compliant primitives while preserving program control flow and call arguments.

```
                  Vulnerable Source File (e.g. auth.js)
                                     |
                                     v
                       +---------------------------+
                       |      SemanticPatcher      |
                       |  - AST Node Replacement   |
                       |  - Import Injections      |
                       |  - Buffer Argument Adjust |
                       +---------------------------+
                                     |
                                     v
                       +---------------------------+
                       |        Unified Diff       |
                       +---------------------------+
                                     |
                        +------------+------------+
                        |                         |
                        v                         v
                   [--dry-run]              [In-Place Edit]
                 Preview Diff in          Write Patched Code
                 Terminal / Review        to File on Disk
```

## 2. Standard Remediation Rules

The patcher automatically executes seven categories of cryptographic upgrades:

| Vulnerable Pattern | Remediated Replacement | Rule Identifier |
| :--- | :--- | :--- |
| `crypto.createHash('md5')` | `crypto.createHash('sha256')` | `PQC-REMEDIATE-MD5-TO-SHA256` |
| `crypto.createHash('sha1')` | `crypto.createHash('sha256')` | `PQC-REMEDIATE-SHA1-TO-SHA256` |
| `crypto.createCipheriv('des-cbc', ...)` | `crypto.createCipheriv('aes-256-gcm', ...)` | `PQC-REMEDIATE-DES-TO-AESGCM` |
| `crypto.createCipheriv('rc4', ...)` | `crypto.createCipheriv('chacha20-poly1305', ...)` | `PQC-REMEDIATE-RC4-TO-CHACHA` |
| `crypto.createCipheriv('aes-128-ecb', ...)` | `crypto.createCipheriv('aes-256-gcm', ...)` | `PQC-REMEDIATE-ECB-TO-GCM` |
| `Math.random()` in crypto context | `crypto.getRandomValues(new Uint32Array(1))[0]` | `PQC-REMEDIATE-PRNG-INSECURE` |
| JWT header `{"alg": "none"}` | `{"alg": "ES256"}` | `PQC-REMEDIATE-JWT-NONE` |

## 3. CLI Usage

### 3.1. Dry-Run Mode (Preview Diff)

Inspect the proposed changes without modifying files on disk:

```bash
pqcanary patch ./src/legacy_hasher.js --dry-run
```

**Output:**
```diff
--- ./src/legacy_hasher.js
+++ ./src/legacy_hasher.js
@@ -12,4 +12,4 @@
 function computeChecksum(buffer) {
-    const hash = crypto.createHash('md5');
+    const hash = crypto.createHash('sha256');
     hash.update(buffer);
     return hash.digest('hex');
 }
```

### 3.2. In-Place File Patching

Apply the patches directly:

```bash
pqcanary patch ./src/legacy_hasher.js
```

## 4. Automated Pull Request Creation Script

Integrate PQCanary patching into an autonomous remediation workflow using the GitHub CLI (`gh`):

```bash
#!/usr/bin/env bash
set -e

BRANCH_NAME="pqcanary-crypto-modernization-$(date +%s)"
TARGET_FILE="./src/services/encryption.js"

# Create a new Git branch
git checkout -b "$BRANCH_NAME"

# Apply semantic patches
pqcanary patch "$TARGET_FILE"

# Check if any changes were made
if git diff --quiet "$TARGET_FILE"; then
  echo "No cryptographic remediation needed for $TARGET_FILE."
  git checkout -
  git branch -D "$BRANCH_NAME"
  exit 0
fi

# Stage and commit the modernized cryptographic code
git add "$TARGET_FILE"
git commit -m "security(crypto): automated post-quantum algorithm modernization via PQCanary"

# Push branch and open Pull Request
git push origin "$BRANCH_NAME"

gh pr create \
  --title "Security: Modernize Cryptographic Primitives to PQC Compliance" \
  --body "Automated pull request generated by PQCanary. Replaced deprecated/classical cryptographic primitives with post-quantum compliant algorithms." \
  --label "security,post-quantum"

echo "Remediation pull request successfully opened."
```
